# poe2filter → FilterBlade Theme

A single-page tool that takes a [poe2filter.com](https://poe2filter.com) loot filter and repaints it with [FilterBlade](https://www.filterblade.xyz) (NeverSink) colours without changing the tiering, the conditions, or what shows or hides. It only edits the cosmetic lines (colours, icons, fonts, beams, sounds).

**Live page:** https://charleslabs.fr/tools/poe2filter-theme.html

## Usage

1. Open the page.
2. Drop in your `.filter` file exported from poe2filter.com.
3. (Optional) Toggle which colour facets and item categories to repaint.
4. Download the recoloured filter.

> Works only with poe2filter.com output, since it keys off that generator's structure. It is not a general filter converter.
