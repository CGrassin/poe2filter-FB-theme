# poe1filter / poe2filter → FilterBlade Theme

Two single-page tools that take a [poe1filter.com](https://poe1filter.com) or [poe2filter.com](https://poe2filter.com) loot filter and repaint it with [FilterBlade](https://www.filterblade.xyz) (NeverSink) colours without changing the tiering, the conditions, or what shows or hides. They only edit the cosmetic lines (colours, icons, fonts, beams, sounds).

**Live pages:**

- Path of Exile 1: https://charleslabs.fr/tools/poe1filter-theme.html
- Path of Exile 2: https://charleslabs.fr/tools/poe2filter-theme.html

## Usage

1. Open the page for your game.
2. Drop in your `.filter` file exported from poe1filter.com or poe2filter.com.
3. (Optional) Toggle which colour facets and item categories to repaint.
4. Download the recoloured filter.

> Works only with poe1filter.com / poe2filter.com output, since it keys off those generators' structure. These are not general filter converters.
